# Editor Toolkit

Premiere Pro panel (Mac + Windows) for the editing team.

**Install:** download [Editor-Toolkit.zip](https://github.com/ces1011/editor-toolkit-releases/releases/latest/download/Editor-Toolkit.zip),
unzip it, quit Premiere Pro, and double-click the installer for your computer ("Install on Mac" or "Install on Windows").
Then in Premiere: Window > Extensions > Editor Toolkit.

**Updates:** the panel shows "Update now" when a new version is out.
